# SolvePnP_Robotics
# Operating Workflow: Monocular Pose Estimation & Full-Process Grasping

This document outlines the step-by-step operating procedure for monocular 3D pose estimation using `solvePnP` with Omniverse Replicator in NVIDIA Isaac Sim, followed by trajectory execution with an Elfin manipulator via ROS 2 and MoveIt.

---

## Phase 1: Monocular Pose Estimation (SolvePnP & SDG)

### 1. Scene Configuration
1. Open your scene in Isaac Sim and add the target **object block** and a **camera**.
2. Ensure the camera lens is positioned so that the object block is clearly visible within its field of view.

### 2. Feature Extraction via Replicator
Generate 2D image coordinates for feature points (corners) using Omniverse Replicator.

Run the standalone script:
```bash
cd ~/isaacsim/isaac-sim-standalone-5.1.0-linux-x86_64
./python.sh /home/nnd/RL_Training/HYH/SDG/official_standalone.py
```

> **Notes & Best Practices:**
> - **Configuration:** Before executing `official_standalone.py`, update the script with your specific USD path and prim paths.
> - **Data Storage:** Output data generated by Replicator is saved directly into the current working directory in the terminal.
> - **Termination (Known Issue):** The script currently does not terminate automatically upon completion. By default, it captures 3 data samples logged as `step0`, `step1`, and `step2`. Once `step2` is displayed in the terminal, manually terminate the process by pressing `Ctrl + C`.

### 3. SolvePnP Verification
Verify the accuracy of the estimated 3D pose:
```bash
./python.sh /home/nnd/RL_Training/HYH/SDG/official_verify.py
```

## Phase 2: Pose Calculation & Grasping Parameter Setup

### 1. Calculate Relative Pose to Robot Base
Execute the `pick_up_example1_with_elfin.py` script to calculate the block's pose relative to the Elfin robot arm base:

```bash
# Script location: /home/nnd/RL_Training/HYH/IsaacSim/source/standalone_examples/api/isaacsim.robot.manipulators/ur10e/
./python.sh /home/nnd/RL_Training/HYH/IsaacSim/source/standalone_examples/api/isaacsim.robot.manipulators/ur10e/pick_up_example1_with_elfin.py
```

> **Note:** Update the translation vector and rotation matrix in `pick_up_example1_with_elfin.py` using the values output by `official_verify.py` in Phase 1 Step 3. You can copy the values directly from the terminal, but ensure comma formatting is maintained.

### 2. Configure Full-Process Grasping Script
Running `pick_up_example1_with_elfin.py` outputs:
- Translation vector relative to the robot base
- Rotation matrix relative to the robot base
- Adaptive short-edge grasp quaternions

> **Important Note:** There is a known issue where quaternion outputs from `pick_up_example` may require adjustment, as quaternion interpretations can differ between Isaac Sim and MoveIt.

Copy these outputs into the master grasping script located at:
`/home/nnd/elfin_robot/Yuhang_elfin_moveit_config/scripts/full-process_grasping1.py`

---

## Phase 3: Simulation & MoveIt Trajectory Execution

### 1. Start Isaac Sim Simulation
1. Launch Isaac Sim and load the scene USD containing the object block and the Elfin 10_L robot arm:
   `/home/nnd/elfin_robot/elfin_description/urdf/elfin10_l/elfin10_l.usd`
2. Click the **Play** button in Isaac Sim.

### 2. Launch MoveIt Demo Package
In a ROS 2 workspace terminal (ensure the workspace & this moveit package is compiled with `colcon build` and sourced):
```bash
ros2 launch Yuhang_elfin_moveit_config demo.launch.py
```

### 3. Run Full-Process Grasping
In another terminal, execute the full grasping script:
```bash
cd ~/elfin_robot/Yuhang_elfin_moveit_config/scripts
python3 full-process_grasping1.py
```
